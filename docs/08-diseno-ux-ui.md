# 8. Diseño y UX Adaptativo

## 8.1 Referencias Visuales Implementadas
- **Dashboard SaaS**: Inspirado en **FundFlow SaaS** con KPIs de alto impacto, tarjetas de balance y gráficos de actividad.
- **Marketplace de Propiedades y Demandas**: Inspirado en **Landify Real Estate CRM** con selector de vista Grid / Lista, badges de comisión 50/50 y mapa Leaflet con pines interactivos.
- **Páginas Independientes y Landing**: Inspirado en las interfaces oscuras modernas con micro-interacciones suaves y WCAG 2.2 AA.
