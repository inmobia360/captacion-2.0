# Voice of Real Estate Spain

Capa de investigación de mercado para alimentar el producto y Premium
Intelligence con problemas observados en conversaciones públicas.

## Regla de uso

La investigación inspira y prioriza specs, pero no sustituye una decisión de
producto ni una especificación aprobada. Cada hallazgo debe conservar fuente,
fecha, persona, evidencia, frecuencia estimada, impacto y nivel de confianza.

## Pipeline

```text
fuente pública → captura ética → normalización → clasificación → síntesis
→ hipótesis → spec → experimento → validación
```

No se deben copiar datos personales, credenciales, contenido privado ni material
protegido más allá de lo necesario para resumir una señal de mercado.
