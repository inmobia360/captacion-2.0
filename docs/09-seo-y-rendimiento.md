# 9. SEO y Rendimiento

## 9.1 Optimizaciones de Rendimiento
- **Compresión Gzip / Brotli**: Activa en servidor LiteSpeed mediante directivas `.htaccess`.
- **Caché de Recursos Estáticos**: 1 mes para imágenes y 1 semana para CSS/JS.
- **Carga Asíncrona**: Scripts y fuentes optimizadas con Google Fonts Inter preconnected.
