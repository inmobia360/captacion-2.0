# Memoria operativa de CAPTACION-2.0

Esta carpeta será mantenida por `secretaria` y supervisada por el CEO.

Archivos recomendados:

- `backlog.md`: tareas abiertas priorizadas.
- `decisions.md`: decisiones aprobadas y su evidencia.
- `blocked.md`: bloqueos, dependencia y decisión requerida.
- `agent-gaps.md`: competencias que todavía no tienen subagente.

La secretaria no inventa estados ni ejecuta despliegues. Solo registra evidencia existente y eleva decisiones al CEO.
