# Adopción de SDD

Compra Captación adopta el flujo:

`Constitución → Spec → Clarificación → Plan → Tareas → Implementación → Validación → Cambio`

Cada funcionalidad nueva o modificación relevante debe pasar por estas fases. La
implementación se hará una tarea cada vez y los cambios de comportamiento se
documentarán primero en la spec.

El objetivo de esta adopción es unificar las superficies pública, profesional y
CRM en un solo producto coordinado. El plan maestro está en
`docs/sdd-master-plan.md`.
