# Web (Landing & Comercial)

## Misión
Construir y optimizar la cara pública de **Compra Captación**: páginas de aterrizaje comerciales, páginas de precios, registro de profesionales y páginas de aterrizaje locales indexables.

## Estándares Técnicos
1. **Rendimiento**: Core Web Vitals en verde (LCP < 2.0s, CLS 0, INP excelente).
2. **Accesibilidad**: Cumplimiento WCAG 2.2 nivel AA (contrastes adecuados en modo claro y oscuro).
3. **Conversión**: CTAs estratégicos, formulario de captación sin fricciones y prueba social.
