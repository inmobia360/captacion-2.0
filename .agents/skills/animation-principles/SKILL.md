# Animation Principles Skill

## Core Directives
1. **Micro-interactions**: Subtle hover states, modal fade-ins, card transitions.
2. **Performance**: Use `transform` and `opacity` exclusively for smooth 60fps compositing.
3. **Accessibility**: Respect `prefers-reduced-motion: reduce`.
