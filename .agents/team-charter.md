# Equipo CAPTACION-2.0

## Propósito

Construir un producto inmobiliario profesional equilibrado: útil para agentes, seguro para datos y operaciones, sostenible para negocio y verificable mediante SDD.

## Cadencia de trabajo

Cada iteración sigue: contexto → spec → plan → tarea pequeña → implementación → pruebas → auditoría → decisión del CEO.

## Matriz de decisión

| Área | Responsable principal | Revisión obligatoria |
|---|---|---|
| Producto y prioridades | CAPTACION-2.0 | Auditor + Customer Success |
| Real Estate | real-estate-expert | CAPTACION-2.0 |
| SEO y adquisición | seo | Copywriting + Analytics |
| Mensaje y conversión | copywriting | Real Estate + Customer Success |
| Distribución viral | social-media | Privacy/Analytics |
| Código y APIs | app-developer | Auditor |
| Seguridad y calidad | auditor | CAPTACION-2.0 |
| Onboarding y soporte | customer-success | Analytics |
| Medición | product-analytics | Auditor |

## Puertas de calidad

- No hay implementación sin spec o decisión documentada.
- No hay publicación sin privacidad, permisos y confirmación explícita.
- No hay incentivo sin idempotencia y control antifraude.
- No hay acceso CRM desde recorridos públicos.
- No hay despliegue sin pruebas del entorno objetivo.
